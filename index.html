Thermal Detector

Goal
Design a device that can detect non-normal temperature changes.
Tools
  • TinkerCAD
  • Onshape
  • Arduino IDE
  • Soldering
Timeline
Sep 2025 – Dec 2025

Results

Alert range70–75°F
SensorTMP36
Power9V

The task was to build a device that detects changes in temperature and lets the user know when the temperature moves above or below a set range of 70–75 °F.

My sensor calculates the temperature from an analog reading of a TMP36, the Arduino converts it, and the LCD shows the result in °F. It reads accurately, but it is not as capable as other temperature sensors because of the TMP36’s restricted temperature range.
